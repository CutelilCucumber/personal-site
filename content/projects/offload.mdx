## The problem

Selling second-hand clothes is tedious. You have to photograph the item, look up the brand, guess the size and condition, research a price, and then type the same details into every marketplace.

## What I built

Offload turns photos into listings. You upload images of an item, and a vision model returns structured data — title, brand, category, size, color, condition, material, and an estimated price — along with its confidence and reasoning. You review and edit the draft, then publish it to eBay through their Inventory API.

## Architecture

- **React + Vite frontend** with dynamic forms that adapt to whatever the model identified.
- **Express 5 REST API** with JWT auth and role-based routes (guest, user, admin).
- **Prisma + PostgreSQL.** Users, items, images, tags, and listings, plus per-user marketplace OAuth tokens so one item can be listed on several marketplaces.
- **Image pipeline.** Multer uploads, `sharp` resizes and converts to WebP, and Supabase handles storage.
- **AI layer.** A prompt that forces strict JSON output, with an optional reasoning mode. The full model response is stored alongside the item so I can audit it.
- Deployed as a Docker image on my Coolify server with its own Postgres.

## What I learned

Third-party OAuth flows (eBay's is not gentle), getting reliable structured output out of an LLM, and modeling data so one product can map to many marketplace listings.
