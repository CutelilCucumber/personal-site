A full-stack blog with separate frontends for readers and authors, both using one Express REST API.

- **JWT authentication** with role-based access: guests can comment, members can post, admins have full control.
- Passwords hashed with **PBKDF2** using Node's built-in crypto module.
- Author dashboard with drafts and publishing, a **TinyMCE** editor, and per-post comment moderation ([admin demo](https://blog-api-admin-sigma.vercel.app)).
- Endpoints documented and tested with a Postman collection.
